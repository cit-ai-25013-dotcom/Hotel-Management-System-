# Hotel-Management-System-
يهدف مشروع نظام إدارة الفندق إلى تنظيم وإدارة غرف الفندق بطريقة بسيطة وسهلة باستخدام لغة ++C  تم تصميم المشروع باستخدام مفاهيم البرمجة كائنية التوجه (OOP)، مثل الكلاسات والكائنات والـ Constructor والتغليف (Encapsulation)، وذلك لتوضيح كيفية استخدام هذه المفاهيم في تطبيق عملي من الحياة اليومية.
